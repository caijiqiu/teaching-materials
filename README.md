## 二、目录结构 / Structure

```
teaching-materials/
├── 01-syllabus/        课程标准、教学大纲
├── 02-lesson-plans/    教案（含教学设计、课堂流程）
├── 03-slides/          课件 PPT / PPTX
├── 04-handouts/        讲义、逐字稿、学习任务单
├── 05-exercises/       习题、考核方案、参考答案
└── 06-papers/          教研论文、教学案例、专著稿件
```

每个目录下按**课程或主题**再分子目录，例如：

```
03-slides/
└── 创新创业教育/
    └── 项目一-开启创新之门.pptx
```

## 三、文件命名规范 / Naming

```
[课程简称]_[项目/单元]_[资料类型]_[版本或日期].扩展名
```

示例：

- `双创_项目一_教案_2026版.doc`
- `生涯规划_生涯彩虹图_课件_2025-09.pptx`
- `大学英语_Unit1_教案_20261029.docx`

约定：不用"新建文档""最终版""最终版2"等无信息名称；一份资料只保留一个现行版本，历史版本放入 `99-archive/`。

## 四、使用说明 / Usage

1. 本仓库资料可自由**下载、课堂使用、教学交流**。
2. 转载、改编或用于公开出版、商业培训前，请先联系作者取得授权。
3. 课件中引用的图片、视频、案例版权归原作者所有，仅作教学演示用，不随本仓库授权。
4. 部分课件含学生作品或个人信息，使用前请自行脱敏。

## 五、体积与格式提示

- 单文件建议控制在 **50 MB** 以内；超过 50 MB 的课件请压缩图片或拆分后上传。
- GitHub 单文件硬上限 100 MB。
- Office 文件（.doc/.docx/.ppt/.pptx）请确认不含敏感信息后再提交。
